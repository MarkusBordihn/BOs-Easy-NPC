# 🧠 Easy NPC: Core

The _**Easy NPC: Core**_ includes the foundational logic for the _Easy NPC_ mod.  
It provides the essential backend systems used by other Easy NPC modules.

## 🔧 What It Does

- 📦 **Includes** the core _Easy NPC_ functionality.
- ⚙️ **Provides** shared backend logic and infrastructure.
- 🧩 **Required by** modules like:
    - `easy_npc-config-ui`
    - `easy_npc-bundle`

## 👨‍💻 Who Should Use This?

This module is best suited for:

- 🖥️ **Server owners**
- 🧪 **Mod developers**
- 🧪 **Modpack developers**
- 🔧 **Advanced users or multiplayer environments**

Use this version if you **don’t need** a built-in configuration UI or want tighter control over how
Easy NPC is integrated.

## 🙅 Not for Regular Players

> ⚠️ Most players should use the **bundled version**, which includes a user-friendly config UI.  
> 👉 Available
> at: [https://www.curseforge.com/minecraft/mc-mods/easy-npc](https://www.curseforge.com/minecraft/mc-mods/easy-npc)

## ✅ Can Be Used Standalone

While it **can** be used on its own, it's primarily designed as a modular backend for more complex
setups.
